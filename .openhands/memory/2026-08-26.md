# 2026-08-26 工作日志

## 修复：DeepSeek 上游废弃 deepseek-chat-direct 模型名

### 现象
dsh 通过 https://117.72.220.114:8648/v1 调用网关时，21:00 左右突然全部 503。
之前几秒还能用（20:58-21:00 有 4 次 200）。

### 根因
DeepSeek 上游 API 在 21:00 左右废弃了 `deepseek-chat-direct` 模型名，
只接受 `deepseek-v4-pro`、`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`。
网关透传 400 到 dsh，dsh 超时。

### 修复
1. gateway.yaml: deepseek-direct provider 的 models 改为 `deepseek-v4-flash`，添加 alias 映射
2. gateway.py: load_config() 构建 `_alias_map`（旧名→新名），chat_completions 入口处先解析别名
3. 添加了诊断日志（超时/不可达/异常时打印具体信息）

### 验证
- `curl -sk https://117.72.220.114:8648/v1/chat/completions -d '{"model":"deepseek-chat-direct",...}'` → 200 ✅
- 日志中可见 `🔀 模型别名解析: deepseek-chat-direct → deepseek-v4-flash`

### 注意
- 别名仅在 gateway.yaml 的 provider 级别声明，语义是"旧名→新名"
- /v1/models 返回的列表里新旧两个名字都存在
