# 2026-08-27 工作日志

## v2.10 质量反馈闭环

### 改动范围
- **DB 迁移**: `usage` 表追加 `checker_score REAL DEFAULT NULL` + `user_feedback INTEGER DEFAULT 0`
- **全局变量**: `_quality_factors` + `_user_factors` 字典
- **检查者评分写入**: `POST /admin/fiber/{id}/commit` 接受 `score` 参数，写入最近一条 usage
- **后台线程**: 30秒循环中取最近20次检查者评分 → 0.5~1.0 质量因子；取最近20次用户反馈 → 0.5~1.5 用户因子
- **权重公式**: `最终权重 = 静态权重 × (1-错误率) × 质量因子 × 用户因子`
- **/admin/feedback**: 用户反馈端点，实时更新用户因子（不等30秒）
- **CLI**: `python3 gateway.py quality` + `python3 gateway.py feedback-stats`
- **配置段**: `gateway.yaml` 新增 `quality_feedback`（enabled/quality_window/quality_min_samples/user_window/update_interval）
- **README**: 新增质量反馈闭环章节 + 版本记录 v2.10

### 设计要点
- 质量因子范围 0.5~1.0（不会完全禁用，熔断负责禁用）
- 用户因子范围 0.5~1.5（不会无限放大或缩小）
- 冷启动保护：不足5个样本时因子=1.0
- 用户反馈实时生效，通过 /admin/feedback 端点即时更新
